A section exists when a numbered heading (`_HEADING_NUMBER_RE`, any `#` level) matching the citation is present; it is non-empty when the lines between that heading and the next heading of equal-or-higher level contain at least one non-blank, non-heading line. A bare `<NAME>.md` (no `§N`/`D<nn>`) needs only the file to locate uniquely. `Design N` reads `repo.root / "design.md"` — the same root file `_render_cited_specs` renders as "design.md §N".
