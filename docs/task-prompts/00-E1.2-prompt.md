Task: Formalise the toolkit-root resolution into a `ToolkitPaths` type exposing `prompts_dir`, `agent_configs_dir`, `agents_dir`, `scripts_dir`; make `aidw doctor` report the toolkit root from `/tmp`.

Requirements:
1. Add a frozen `ToolkitPaths` dataclass in `aidw/paths.py`, mirroring the existing `TargetRepo` shape. It is a distinct type from `TargetRepo` (EXTRACTION.md §3.1 "use two distinct types … rather than one `root: Path`"). Sole construction entry point is the classmethod `ToolkitPaths.resolve() -> ToolkitPaths`; callers never build it by hand.
2. Expose exactly `root`, `prompts_dir`, `agent_configs_dir`, `agents_dir`, `scripts_dir` — all absolute `.resolve()`d `Path`s. `root` is the toolkit root (§3.1 names it and the Done-when reports it); the four dirs are the fields the roadmap lists.
3. Resolve `root` from the package location, never from git or cwd: delegate to the existing `toolkit_root()` (`aidw/paths.py:toolkit_root`, i.e. `Path(__file__).resolve().parent.parent`). Do not call `repo_root()` or any git command in `ToolkitPaths`.
4. Derive the dirs per §3.1/§3.12: `prompts_dir = root/"prompts"`, `agent_configs_dir = root/"agent-configs"`, `agents_dir = root/"agents"`, `scripts_dir = prompts_dir/"scripts"` — §3.1 names the script dir as `prompts/scripts/`, not `root/scripts` (matches `inventory.REQUIRED_SCRIPTS`, which is relative to `prompts_dir`).
5. Keep the transitional helpers working unchanged: `toolkit_root()` returns `ToolkitPaths.resolve().root`; `aidt_root()` and `runs_dir()` keep their current behaviour. E1.4 deletes the two aliases — do not do that here.
6. Add a doctor check that reports the toolkit root. Place it in `collect_checks()` (`aidw/doctor.py`) in the first checks list, *before* the `repo_root()` try/except that returns early on `RepoNotFoundError` — otherwise `aidw doctor` from `/tmp` (no repo) never prints it. Derive it from `ToolkitPaths.resolve()`, and keep the existing prompts/agent-configs checks working (they currently read `aidt_root()`).
