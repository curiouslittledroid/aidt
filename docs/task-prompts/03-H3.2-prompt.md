Traps / prior review findings:
- Base mismatch → the box is silently never ticked on a non-main base. The prompts never pass `--base` to `aidw gate run`, so every recorded outcome is computed against `verification.BASE_DEFAULT` ("main"); recomputing with `repo.base_branch` would differ and match nothing. Use `tree_identity`'s default `base`, matching the subprocess.
- Scope mismatch → the box is silently never ticked. `tree_identity` with no (or a different) `ignore` includes `implementation_results_dir`/`architecture_dir`/`task_prompts_dir`, whose changed/untracked files make the recomputed tree differ from the outcomes `aidw gate run` recorded; then even a green run matches nothing and skips. Use exactly the four resolved dirs from req 3.
- Evaluate before `run_stage` and **route the skip around `settle_tick` too**: `_settle_roadmap_tick` runs whenever `exit_code in (None, 0)`, so it would re-read the unchanged file and stamp `tick: already` onto the `skipped` record. Put the check where every path that can dispatch I7 reaches it before `run_stage`: serial `execute()` **and** the `--parallel` member dispatch — group members bypass `execute()` (`pool.submit(run_stage, …)`, `aidw/workflows/implement.py`), and `validate_parallel_groups` refuses only unknown/double-listed members, so a repo-declared group containing `update-roadmap` would otherwise tick with no evidence check at all (I7 is not in the default `parallel_groups` pair).
- Read `state.gate_outcomes` from the in-memory `state` at I7 time, not a fresh `state.load()` and not `run.log`: `run_stage`/`save` already merged I5's subprocess-recorded outcomes (H0.1); a fresh load or re-derivation re-introduces exactly the boundary loss H0.1 closed.
- `skipped` is a distinct status, not `failed` and not H3.1's `succeeded`-`already` no-op. Setting `error` (rendered as a failure) or reusing the resume-skip's bare `print("[skipped]")` with no record breaks the phase rule (observable from `state.json`/`run.log` without a transcript).

- `--dry-run` returns before `execute()`, so the condition is never evaluated there — I7 must still plan with `when=evidence-green` carried, and dry-run must not fail or skip on missing evidence.
