Traps / prior review findings:
- Missing period after the id inside the bold collapses every entry to the epic id and `find_task` finds nothing — the doc's own example must use `**E5.1. …**`, and the test must assert no `.`-less ids (E0.7 rule 1).
- Phase id comes from the filename, not the `# Phase` heading — an example file `07 - Example Roadmap.md` must carry a matching `# Phase 07:` (or `7:`, which `parse_file`'s phase guard — `group(1) in (phase, phase.lstrip("0"))` — tolerates; `PHASE_RE` itself strips nothing); the parsed `phase` is still the filename's `07`.
- A blank line *inside* the multi-line `Done when:` block truncates it — `prompt.py:_done_when_block` stops at the first blank line after the `Done when:` line, and `parse_file` fills `done_when` from that first physical line only — so the example's continuation lines must stay contiguous with the `Done when:` line.
